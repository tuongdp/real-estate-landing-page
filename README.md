# Real Estate Landing Page

A real estate landing page built based on a Figma design.

## Design

Figma: [Real Estate Landing Page](https://www.figma.com/design/Zs7vjnMWc3jj09J94gr57L/01.-Real-Estate-Landing-Page--Easy---1-?node-id=2-335&m=dev)

## Technologies

* HTML5
* CSS3

## Features

* Clean and modern user interface
* Responsive layout
* Real estate landing page design
* Organized CSS styles

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/real-estate-landing-page.git
```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.

## Purpose

This project was created to practice converting a Figma design into a website using HTML and CSS.
